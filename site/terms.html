β版サービス

Alt Notifyは、本人承認済みのDiscordアカウント連携と、Discord公式Bot APIで受信した対象イベントの通知を補助するβ版サービスです。Alt NotifyはDiscordとは独立したサービスです。利用者はDiscordを利用するために必要な最低年齢を満たし、利用地域でDiscordを利用する資格を有する必要があります。Alt Notifyは生年月日や年齢確認情報を収集しません。

通知の到達、即時性、完全性、保存データの無欠損を保証しません。Discordの障害、権限変更、DM拒否、ネットワーク障害、VM障害、イベント欠落などで利用できない場合があります。

禁止事項

  • 本人の同意なく他人のアカウントを連携すること
  • Discord User Token、Self-Bot、回避的な自動化を使うこと
  • 大量リクエスト、スパム、嫌がらせ、違法行為、第三者の権利侵害
  • Bot、Discord API、サービスの脆弱性や権限を悪用すること
  • Botやサービスの認証情報を第三者へ共有すること

アカウントデータ

/account refresh は本人の保存済み表示情報を現在のDiscord情報へ更新します。/unlink は個別連携を解除します。/account delete は本人のactive dataを削除し、ディスク上の削除と新しい検証済みbackupを確認した後、既知のOracle旧コピーを削除します。削除前backupは通常の復元候補から除外します。Windows PCがofflineの場合、VM外backupの物理削除は次回接続まで遅れることがあります。削除前backupは通常の復元に使わず、次回正常実行時に削除します。すべての媒体からの即時物理削除を保証するものではありません。

通知履歴と重複排除情報は7日後に削除します。Oracle VM内backupは最新7世代・14日以内、ファイル暗号化したWindows VM外backupは最新14世代・30日以内を保持方針とします。鍵はbackupとは別にOS保護領域で管理します。詳細はPrivacy Policyを確認してください。

仕様変更・終了

β運用中は、サービスの仕様変更、停止、利用制限、終了を行う場合があります。公開βでは課金機能を提供していません。

お問い合わせ

一般的な問い合わせ・不具合報告は GitHub Issues を利用できます。公開Issueに個人情報・認証情報を投稿しないでください。保存済みデータの削除は/account delete、個別のサブアカウント連携解除は/unlinkで行ってください。

適用される規約

利用者はDiscordおよび所属サーバーの規約に従うものとします。Discord Terms of Service と Discord Developer Terms を遵守してください。

β版サービス

Alt Notifyは、本人承認済みのDiscordアカウント連携と、Discord公式Bot APIで受信した対象イベントの通知を補助するβ版サービスです。Alt NotifyはDiscordとは独立したサービスです。

通知の到達、即時性、完全性、保存データの無欠損を保証しません。Discordの障害、権限変更、DM拒否、ネットワーク障害、VM障害、イベント欠落などで利用できない場合があります。

禁止事項

  • 本人の同意なく他人のアカウントを連携すること
  • Discord User Token、Self-Bot、回避的な自動化を使うこと
  • 大量リクエスト、スパム、嫌がらせ、違法行為、第三者の権利侵害
  • Bot、Discord API、サービスの脆弱性や権限を悪用すること
  • Botやサービスの認証情報を第三者へ共有すること

アカウント削除

/unlink は個別連携を解除し、未送信・処理中の通知を停止します。過去の通知履歴は保持される場合があります。/account delete は連携解除後でも本人の登録データ、監視設定、通知履歴に保存された本人情報を削除します。バックアップ上のコピーは保持期間まで残る場合があります。

仕様変更・終了

β運用中は、サービスの仕様変更、停止、利用制限、終了を行う場合があります。公開βでは課金機能を提供していません。

お問い合わせ

一般的な問い合わせは GitHub Issues を利用できます。公開Issueに個人情報・認証情報を投稿しないでください。

適用される規約

利用者はDiscordおよび所属サーバーの規約に従うものとします。Discord Terms of Service と Discord Developer Terms も確認してください。

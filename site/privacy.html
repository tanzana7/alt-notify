Privacy Policy

最終更新：2026-10-13

DBに保存する情報

  • Discord User ID、username / display name、連携関係、プラン情報
  • Guild ID、Channel ID、Message ID、対象Role ID、watch設定
  • 連携コードのハッシュと期限、通知キュー、重複排除、送信試行・エラー情報

一時的に扱う情報

Guild名・Channel名は通知表示のためDiscordのキャッシュから参照します。メンバー情報も通知判定のためメモリ上のキャッシュで扱います。これらの名前はDBに保存しません。

保存しない情報

メッセージ本文、添付ファイル、DM本文、Discordパスワード、Discord User Token、キーワード、全メンバー一覧は保存・転送しません。Message Content Intentも使用しません。非公開スレッドは通知対象外です。

利用目的

本人承認済みのアカウント連携、通知判定、重複排除、送信再試行、障害調査、バックアップと復元確認に利用します。内部IDは必要な処理に使いますが、ユーザー向け通知DMには表示しません。

公開サイトのアクセス解析

公開LPではGoogle Analytics 4を利用し、ページ閲覧と主要リンク（Bot招待、GitHub、Privacy、Terms）の利用状況を統計的に把握します。目的は利用状況の把握とサービス改善です。GoogleのタグがCookie等の識別子や接続情報を処理する場合があります。当サイトの計測イベントにはDiscord User ID、Guild ID、Channel ID、Message ID、username、連携コード、メッセージ本文、DM本文、添付情報、Bot招待URL全体、URL queryの値を含めません。Googleによる情報の取り扱いはGoogleのプライバシーポリシー等に従います。Botの通知処理にGA4は使用しません。

保存場所とバックアップ

本番データは運営者が管理するOracle Cloud VM上のSQLiteに保存します。日次Oracle backupは最新7世代・14日以内を保持します。Oracle VMから非公開のCloudflare R2へ、AES-256-GCMで暗号化したbackupを最新14世代・30日以内の方針で保存します。R2からのdownload、復号、別DBへのrestore verify、SQLite integrity、privacy generation一致が成功した場合だけbackup成功として扱います。暗号鍵はOracle上のroot-onlyファイルに置き、Oracleとは独立したWindows DPAPI保護の復旧用コピーを保持します。/account delete後は削除後の世代でbackupを更新し、削除前世代は通常の復元元として使用しません。R2上の旧暗号化世代は保持期限・世代整理の範囲で残る場合があります。backupに本文、Bot Token、平文連携コードは含みません。

外部サービス

Discord公式API、Oracle Cloud、Cloudflare R2、Healthchecks.ioを利用します。HealthchecksにはGateway・キュー・通知判定の予期しない失敗・R2バックアップの鮮度を示すheartbeat/failのみを送り、Discordアカウント情報やメッセージ情報は送信しません。

削除・表示情報の更新

/account refresh は実行者本人の保存済みusernameと通知履歴上の表示名を現在のDiscord情報へ更新します。/unlink は個別連携を解除します。/account delete は本人のactive dataを削除し、削除後のprivacy generationに一致するbackupを確認した後、削除前backupを通常の復元候補から除外します。R2上の旧世代は保持・世代整理の範囲で残る場合があります。すべての媒体からの即時物理削除を保証するものではありません。

保持期間と削除

メイン登録は/account deleteまで、サブ連携は/unlinkまたは/account deleteまで、監視設定は対象連携またはアカウント削除まで保持します。通知履歴と重複排除情報は7日後に削除します。Oracle backupは最新7世代・14日以内、暗号化したCloudflare R2 backupは最新14世代・30日以内を保持方針とします。削除前backupは通常の復元候補から除外します。運用ログは最大30日保持します。

お問い合わせ

一般的な問い合わせ・不具合報告は GitHub Issues を利用できます。公開Issueに個人情報・認証情報を投稿しないでください。保存済みデータの削除は/account delete、個別のサブアカウント連携解除は/unlinkで行えます。

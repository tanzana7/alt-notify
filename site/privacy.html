Privacy Policy

最終更新：2026-10-02

扱う情報

  • Discord User ID、username / display name
  • Guild ID / Guild名、Channel ID / Channel名
  • Message ID、対象Role ID
  • メイン・サブの連携関係、watch設定、plan情報
  • 通知queue、重複排除、送信試行・retry・エラー情報

保存しない情報

メッセージ本文、添付ファイル、DM本文、Discordパスワード、Discord User Token、キーワード、全メンバー一覧は保存・転送しません。Message Content Intentも使用しません。

利用目的

本人承認済みのアカウント連携、通知判定、重複排除、送信再試行、障害調査、バックアップと復元確認に利用します。内部IDは必要な処理に使いますが、ユーザー向け通知DMには表示しません。

保存場所とバックアップ

本番データは運営者が管理するOracle Cloud VM上のSQLiteに保存し、同一環境内に世代バックアップを保持します。削除後もバックアップ保持期間中は古いデータが残る場合があります。

外部サービス

Discord公式APIを利用します。HealthchecksのURLが設定されている場合のみ、Gateway・キュー・失敗状態を示すheartbeat/failリクエストを送信します。Discordのメッセージ内容は外部監視へ送信しません。

削除

/unlink は個別連携を解除し、/account delete は本人に紐づく登録データ、監視設定、未送信通知を削除します。バックアップ上のコピーは保持期間まで残る場合があります。

お問い合わせ

個人情報に関する問い合わせ先は、運営者が案内する連絡先を使用してください。

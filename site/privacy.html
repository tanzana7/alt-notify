Privacy Policy

最終更新：2026-10-05

DBに保存する情報

  • Discord User ID、username / display name、連携関係、プラン情報
  • Guild ID、Channel ID、Message ID、対象Role ID、watch設定
  • 連携コードのハッシュと期限、通知キュー、重複排除、送信試行・エラー情報

一時的に扱う情報

Guild名・Channel名は通知表示のためDiscordのキャッシュから参照します。メンバー情報も通知判定のためメモリ上のキャッシュで扱います。これらの名前はDBに保存しません。

保存しない情報

メッセージ本文、添付ファイル、DM本文、Discordパスワード、Discord User Token、キーワード、全メンバー一覧は保存・転送しません。Message Content Intentも使用しません。非公開スレッドは通知対象外です。

利用目的

本人承認済みのアカウント連携、通知判定、重複排除、送信再試行、障害調査、バックアップと復元確認に利用します。内部IDは必要な処理に使いますが、ユーザー向け通知DMには表示しません。

保存場所とバックアップ

本番データは運営者が管理するOracle Cloud VM上のSQLiteに保存します。日次バックアップは同VM内で最新7世代かつ14日以内を保持します。VM外コピーは運営者管理のWindows PCに保存し、最新14世代かつ30日以内を保持方針とします。PCが停止・未ログオンなど利用不能な間は削除処理が実行されず、次回正常実行時に期限超過分を削除します。削除済みデータもバックアップの削除まで残る場合があります。転送時にSHA-256とSQLite整合性を確認します。バックアップはメッセージ本文、Bot Token、平文連携コードを含みません。

外部サービス

Discord公式API、Oracle Cloud、Healthchecks.ioを利用します。HealthchecksにはGateway・キュー・失敗状態・VM外バックアップの鮮度を示すheartbeat/failのみを送り、Discordアカウント情報やメッセージ情報は送信しません。

削除

/unlink は連携を解除し、そのアカウントへの今後の通知を停止します。未送信・処理中の通知から対象を除き、他の対象がいなければ取消します。送信済みなど過去の通知履歴は保持される場合があります。/account delete は連携の有無にかかわらず、実行した本人の保存済みデータを削除します。unlink後でも、送信済み・失敗・取消済みを含む通知履歴から本人のIDと表示名を除去できます。バックアップ上のコピーは保持期間中残る場合があります。

保持期間と削除

メイン登録は/account deleteまで、サブ連携は/unlinkまたは/account deleteまで、監視設定は対象連携またはアカウント削除まで、entitlementは/account deleteまで保持します。送信済み・失敗・取消済み通知履歴と重複排除情報は7日後に定期削除します。使用済みまたは期限切れの連携コード情報も定期削除します。systemd運用ログは最大30日保持し、メッセージ本文、Bot Token、平文連携コードはログに記録しません。Oracle backupは最大14日、Windows backupは30日を保持方針とします。Windows PC利用不能時は次回正常実行まで削除が遅れます。

お問い合わせ

一般的な問い合わせは GitHub Issues を利用できます。公開Issueに個人情報・認証情報を投稿しないでください。個人情報を含む問い合わせ用の非公開窓口は、運営者が承認した連絡先の確定後に案内します。データ削除は/account delete、個別連携解除は/unlinkから行えます。

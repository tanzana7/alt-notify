Privacy Policy

最終更新：2026-10-06

DBに保存する情報

  • Discord User ID、username / display name、連携関係、プラン情報
  • Guild ID、Channel ID、Message ID、対象Role ID、watch設定
  • 連携コードのハッシュと期限、通知キュー、重複排除、送信試行・エラー情報

一時的に扱う情報

Guild名・Channel名は通知表示のためDiscordのキャッシュから参照します。メンバー情報も通知判定のためメモリ上のキャッシュで扱います。これらの名前はDBに保存しません。

保存しない情報

メッセージ本文、添付ファイル、DM本文、Discordパスワード、Discord User Token、キーワード、全メンバー一覧は保存・転送しません。Message Content Intentも使用しません。非公開スレッドは通知対象外です。

利用目的

本人承認済みのアカウント連携、通知判定、重複排除、送信再試行、障害調査、バックアップと復元確認に利用します。内部IDは必要な処理に使いますが、ユーザー向け通知DMには表示しません。

保存場所とバックアップ

本番データは運営者が管理するOracle Cloud VM上のSQLiteに保存します。日次Oracle backupは最新7世代・14日以内を保持します。/account delete後はディスク上の削除と削除後の整合性確認済みbackupを確認してから、既知のOracle旧backup・一時コピーを削除します。Windows VM外コピーは最新14世代・30日以内を保持し、ファイルレベルで暗号化します。鍵はbackupとは別にWindows DPAPIで保護します。Windows PCが停止・未ログオンの場合、物理削除は次回接続・正常実行まで遅れる場合があります。削除前backupは通常の復元元として使用せず、次回正常実行時に削除します。backupに本文、Bot Token、平文連携コードは含みません。

外部サービス

Discord公式API、Oracle Cloud、Healthchecks.ioを利用します。HealthchecksにはGateway・キュー・通知判定の予期しない失敗・VM外バックアップの鮮度を示すheartbeat/failのみを送り、Discordアカウント情報やメッセージ情報は送信しません。

削除・表示情報の更新

/account refresh は実行者本人の保存済みusernameと通知履歴上の表示名を現在のDiscord情報へ更新します。/unlink は個別連携を解除します。/account delete は本人のactive dataを削除し、ディスクで確認した後、削除前backupを通常の復元候補から除外します。Windows PCが利用不能な間はVM外コピーの物理削除が次回接続まで遅れる場合があります。すべての媒体からの即時物理削除を保証するものではありません。

保持期間と削除

メイン登録は/account deleteまで、サブ連携は/unlinkまたは/account deleteまで、監視設定は対象連携またはアカウント削除まで保持します。通知履歴と重複排除情報は7日後に削除します。Oracle backupは最新7世代・14日以内、暗号化したWindows backupは最新14世代・30日以内を保持方針とします。Windows PC停止中は期限超過コピーの物理削除が次回正常実行まで遅れる場合があります。運用ログは最大30日保持します。

お問い合わせ

一般的な問い合わせ・不具合報告は GitHub Issues を利用できます。公開Issueに個人情報・認証情報を投稿しないでください。保存済みデータの削除は/account delete、個別のサブアカウント連携解除は/unlinkで行えます。

# 身内βガイド

## 貼り付け用

1. Botを対象サーバーへ招待
2. 本垢で `/main set`
3. 本垢で `/link issue` → コードをサブ垢へ渡す
4. サブ垢で `/link approve` → コード入力 → 承認ボタン
5. Bot導入済み・サブ垢参加中のサーバーは自動監視
6. 停止はそのサーバーで `/watch off`、再開は `/watch on`
7. 確認は `/status` と `/watch status`

直接メンションと全体メンションを本垢へ通知します。通常メッセージ、DM、メッセージ本文は対象外です。

## 詳細

- Freeのテスト上限はサブ垢5件です。
- 連携承認はサブ垢本人が承認ボタンを押してください。
- サブ垢が参加していないサーバーからは通知されません。
- `/unlink` は個別連携解除、`/account delete` は本人の登録データ削除です。
- DM拒否、権限不足、DiscordやVMの障害時は通知できないことがあります。
- 本文や添付は保存しません。問題があれば、時刻・サーバー名・コマンド結果だけを運営者へ知らせてください。

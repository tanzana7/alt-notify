# 身内βガイド

## 貼り付け用

1. Botを対象サーバーへ招待
2. 本垢で `/main set`
3. 本垢で `/link issue` → コードをサブ垢へ渡す
4. サブ垢で `/link approve` → コード入力 → 承認ボタン
5. Bot導入済み・サブ垢参加中のサーバーは自動監視
6. 停止はそのサーバーで `/watch off`、再開は `/watch on`
7. 確認は `/status` と `/watch status`

β版では、通常Freeユーザーはサブアカウントを1つまで無料で連携できます。開発者・テスト用権限は5つまでです。直接メンション、ロールメンション、全体メンションを本垢へ通知します。通常メッセージ、DM、メッセージ本文は対象外です。

## 詳細

- Freeのβ版上限はサブ垢1件です。既存の超過連携は削除せず、新規連携だけ拒否します。
- 連携承認はサブ垢本人が承認ボタンを押してください。
- 同じDiscordアカウントをメインとサブの両方に新規登録することはできません。既存の兼任状態は `/status` で確認でき、`/account delete` は両方を削除します。
- サブ垢が参加していないサーバーからは通知されません。
- `/unlink` は個別連携解除です。過去履歴を含む保存データの削除は、unlink後でも `/account delete` で行えます。バックアップは保持期間中残る場合があります。
- DM拒否、権限不足、DiscordやVMの障害時は通知できないことがあります。
- 本文や添付は保存しません。問題があれば、時刻・サーバー名・コマンド結果だけを運営者へ知らせてください。

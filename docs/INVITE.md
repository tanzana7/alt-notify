# Bot招待

現在のApplication IDを使った最小権限の招待URLです。

https://discord.com/oauth2/authorize?client_id=1551215506722132120&scope=bot%20applications.commands&permissions=66560

権限値 `66560` は `View Channel` と `Read Message History` のみです。管理者権限、メッセージ送信権限、メンバー管理権限は含めません。コマンド利用にはDiscord側のアプリコマンド利用条件も必要です。

通知したいチャンネルをBotが閲覧できるようにしてください。Bot未導入のサーバーは自動監視されません。

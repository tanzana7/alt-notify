# 公開ページ用説明文

アプリ名は設定値 `APP_NAME` を表示名の基準にします。現在の既定値は AltNoti です。

## 1行

別垢の通知に、本垢で気づけるDiscord通知集約Bot。

## 短文（80〜100字目安）

複数のDiscordアカウントを連携し、サブ垢への直接メンションや全体メンションを本垢のDMで確認できます。本文は保存・転送せず、参加中サーバーだけを対象にします。

## 詳細（300〜500字目安）

別垢の通知に、本垢で気づけるDiscord Botです。メインアカウントとサブアカウントを本人承認で連携すると、Botが導入され、サブアカウント自身も参加しているサーバーを自動監視します。直接メンションは優先して通知し、複数アカウントへの通知は本垢向けにまとめます。特定サーバーだけ止めたいときは `/watch off`、再開は `/watch on`。通常のメッセージやDM、キーワード通知は対象外で、メッセージ本文・添付ファイルは保存しません。β版では通常Freeユーザーはサブアカウントを1件まで無料で連携できます。Discordの仕様、権限、障害、DM拒否などにより通知できない場合があります。

## 主な機能

- 本人承認によるメイン・サブアカウント連携
- 直接メンションの優先通知と全体メンションの集約
- サーバー単位の自動監視、`/watch off`、`/watch on`
- `/status`、`/watch status`、`/help`
- `/unlink` と `/account delete`
- 本文を保存しない通知設計

## 導入

1. Botを必要なサーバーへ招待します。
2. メインアカウントで `/main set`、続けて `/link issue`。
3. サブアカウントで `/link approve`、コード入力、承認ボタン。

## FAQ

**毎回 `/watch on` が必要ですか？**
いいえ。連携承認後、Bot導入済みでサブアカウントが参加中のサーバーは自動監視します。明示的にOFFにしたサーバーだけ `/watch on` で再開します。

**本文は通知されますか？**
いいえ。通知の種類、サーバー、チャンネル、対象アカウントなどを本文なしで知らせます。

**連携を消すには？**
個別解除は `/unlink`、保存された自分の登録データ全体の削除は `/account delete` です。

## サーバー管理者向け

Botには対象チャンネルの閲覧とメッセージ履歴の閲覧が必要です。管理者権限は要求しません。Botを導入していないサーバー、またはサブアカウントが参加していないサーバーは通知対象になりません。
